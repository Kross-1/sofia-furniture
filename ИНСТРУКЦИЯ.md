# Инструкция по запуску сайта "Сафия"

## Системные требования

### Необходимое ПО
- **Node.js** версия 18.0.0 или выше ([скачать с официального сайта](https://nodejs.org/))
- **pnpm** (менеджер пакетов, устанавливается через npm)

### Установка pnpm
```bash
npm install -g pnpm
```

## Установка и запуск

### 1. Установка зависимостей
```bash
cd sofia-furniture
pnpm install
```

### 2. Режим разработки (Development)
```bash
pnpm dev
```
или
```bash
npx vite
```

После запуска сайт будет доступен по адресу: **http://localhost:5173**

В режиме разработки:
- Автоматическая перезагрузка при изменениях файлов
- Отображение ошибок в консоли браузера
- Hot Module Replacement (HMR)

### 3. Сборка для production
```bash
pnpm build
```
или
```bash
npx vite build
```

Результат сборки появится в папке `dist/`:
- Оптимизированные и минифицированные файлы
- Готовые к деплою на любой хостинг

### 4. Просмотр production-сборки локально
```bash
pnpm preview
```
или
```bash
npx vite preview
```

## Функционал админ-панели

### Доступ
Админ-панель доступна по пути `/admin`

### Раздел "Контент"
Позволяет загружать медиа-контент для страниц:

1. **Главная страница**
   - Фон главного экрана (изображение)
   - Видео главного экрана (цикличное)

2. **Страница "О нас"**
   - Фон страницы

3. **Страница "Контакты"**
   - Фон страницы

### Как загрузить файл
1. Откройте раздел нужной страницы
2. Нажмите кнопку "Загрузить файл"
3. Выберите изображение (PNG, JPG, WebP) или видео (MP4, WebM)
4. Файл преобразуется в base64 и сохраняется в localStorage

### Как использовать URL
1. Введите прямую ссылку на изображение/видео в поле URL
2. Нажмите "Сохранить изменения"

### Видео особенности
- Видео воспроизводится автоматически
- Видео зацикливается (loop)
- Видео воспроизводится без звука (muted)

## Переключение темы

### Дневной/Ночной режим
В правой части шапки сайта есть кнопка переключения темы:
- ☀️ (иконка солнца) — переключение на светлую тему
- 🌙 (иконка луны) — переключение на тёмную тему

### Как это работает
- Тема сохраняется в localStorage браузера
- При следующем посещении сайт запомнит выбранную тему
- CSS-переменные автоматически меняются при переключении

## Деплой на хостинг

### Подготовка
```bash
pnpm build
```

### Структура для загрузки
После сборки в папке `dist/`:
- `index.html` — главная страница
- `assets/` — оптимизированные JS/CSS файлы
- статические файлы из `public/`

### Варианты деплоя

#### 1. GitHub Pages
1. Установите `gh-pages`:
   ```bash
   pnpm add -D gh-pages
   ```
2. Добавьте скрипт в package.json:
   ```json
   "deploy": "gh-pages -d dist"
   ```
3. Запустите:
   ```bash
   pnpm deploy
   ```

#### 2. Любой статический хостинг
Просто загрузите содержимое папки `dist/` на сервер.

## Если что-то пошло не так

### Ошибка при установке pnpm
```bash
npm install -g pnpm --force
```

### Ошибка при сборке
```bash
# Очистите кэш
pnpm store prune

# Переустановите зависимости
rm -rf node_modules
pnpm install
```

### Проблемы с Node.js версией
```bash
# Проверьте версию
node -v

# Используйте nvm для смены версии
nvm use 18
```
